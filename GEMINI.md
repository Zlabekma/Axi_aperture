# PROJECT: Axisymmetric Aperture Library (axi_ap)

## Overview
This library calculates electromagnetic fields and optical forces generated by light passing through axisymmetric apertures (e.g., Bessel-Gaussian beams). It uses a vector diffraction model beyond the paraxial approximation.

## Core Structure
- **Parameters (`params`)**: Physical constants (SI/CGS) and beam properties.
- **Apertures (`bessel_aperture`)**: Handles the expansion of an incident field into a discrete basis (e.g., Bessel modes). Stores coefficients (`coeffs`).
- **Operators (`Operators`)**: The math engine. Calculates field components (`Ex`, `Ey`, `Ez`) and their derivatives at any point in 3D space.

## Mandatory Workflow Standards

### 1. Physical Integrity First
- **Always verify units.** If SI is used, ensure constants like `epsilon_0` are handled correctly.
- **Vector Nature:** Do not simplify fields to scalar approximations unless specifically requested. The Ez component and field derivatives are critical for optical trapping.

### 2. Simplicity & Clarity
- **Surgical Changes:** Modify only what is necessary. Avoid large refactors unless the current structure is "stupid" or redundant (e.g., passing the same variable three times).
- **Explicit over Implicit:** Prefer clear variable names and explicit math over clever "magic" logic.

### 3. Verification Protocol
- **Check Assumptions:** Before editing a file, read its current imports and class structure to match the existing style.
- **Empirical Testing:** After a change, run the `example/Simple_gaussian.py` or equivalent to ensure no regressions.

### 4. Communication
- **When in Doubt, Ask:** If a physical convention is ambiguous (e.g., phase sign convention, polarizability units), stop and ask for clarification.
